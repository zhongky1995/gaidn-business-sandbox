# GAIDN 企业 AI 经营沙盘

[打开在线沙盘](https://zhongky1995.github.io/gaidn-business-sandbox/)

从企业已有经营积累出发，探索可以接入 AI 的方向。纯前端运行，不需要 API key，参数与图片在使用者浏览器中处理。

## 使用

1. 复制网页内的完整提示词，或下载 SKILL.md，发给常用大模型并介绍主营业务。
2. 将返回的参数导入网页，核对和修改事实。
3. 生成经营类型、径向关系图、AI 化建议与适用的情景曲线。
4. 保存 PNG 图片，或下载参数供下次修改。

可先点击“使用示例”体验六类虚构企业，以及信息不足、组合业务两个边界案例。示例标识保留在结果图中。

## 运行与维护

可以直接在浏览器打开 `dist/index.html`，也可以通过上方 GitHub Pages 链接使用。离线功能没有第三方依赖；在线版本另外加载 Google Analytics 4 做基础访问与操作统计。

- `app/model.js`：参数校验、六类判别与固定建议规则。
- `app/skill.txt`：内嵌提示词与可下载 SKILL.md 的完整内容。
- `app/poster.js`：页面与 PNG 共用的结果图。
- `app/ui.js`、`app/styles.css`、`app/shell.html`：页面交互与样式。
- `app/examples.js`：虚构示例。
- `docs/index.html`：GitHub Pages 发布文件。

修改后执行 `python3 publish.py`，同时更新单文件版本和 Pages 目录。将改动提交到 `main` 后，GitHub Pages 从 `/docs` 发布。规则检查：`node --test tests/model.test.cjs`。

## 说明

六种类型是本工具参考价值配置逻辑做的产品细分，不是经过企业样本验证的评分量表。曲线只表达条件满足时的能力变化节奏，不预测营收、日期或增长率。真实企业适配与外部模型提取效果仍需试用。

网页不调用大模型或上传参数，也不自动保存草稿；关闭前可下载参数。外部大模型对话在使用者自己选择的平台完成。

## 访问统计

线上 GA4 衡量 ID：`G-R3SEBYCRSR`。配置在 `app/analytics-config.json`；只有正式 HTTPS 地址会加载标签，直接打开文件或 localhost 不发送统计。使用 `?ga_debug=1` 可把当前会话事件标记为调试流量，并在浏览器控制台检查白名单事件。

固定事件覆盖提示词复制、skill 下载、参数导入、诊断生成、修改、图片生成与下载、参数下载和原生分享。仅发送固定枚举，例如成功/失败和示例/用户资料；不发送企业名称、介绍、证据、参数、图片或下载文件名。页面地址不包含查询参数或片段，来源地址只保留来源域名。Google 标签会按 GA4 机制收集访问和浏览器标识。

GA4 网页数据流已关闭增强型自动采集，以使用本站定义的操作事件。基础 `page_view` 每次加载发一次；其他事件见 `ANALYTICS.md`。埋点或 Google 标签被拦截时，沙盘的导入、诊断与图片导出继续可用。
