# GAIDN · 企业 AI 经营沙盘

v5.1.0：从企业业务、客户与收入理解已有积累，展示六类企业优势和一个AI优先方向，再匹配四套固定经营情景。起步工作仅作例子，诊断范围为整家企业。

[在线使用](https://zhongky1995.github.io/gaidn-business-sandbox/) · [妙搭公开副本](https://ycntefqc810o.feishu.link/app/app_17g1ae49dbx)

## 使用

复制页面内完整提示词给常用AI，提供脱敏企业介绍，AI主动联想机会，最多追加一个关键问题，整理参数。把AI返回的schema5.0参数粘贴或上传到页面，核对后生成海报、查看依据并下载1080×1968 PNG。核对页默认只展开企业名称和业务；其余为建议摘要及按需修改。客户、收入、证据和金句无需逐项填写。六个内置示例均为虚构企业。

## 判断规则

上部由六类优势选择主视觉：知识资产（聚合星核）、流程运营（连续环流）、专家经验（经验辐射）、项目资产（项目星团）、资源连接（双核引力）、协作网络（多中心星网）。三项真实积累中第一项突出。图形是组织方式示意，不代表评分。

经营基础readiness独立匹配下部情景：usable→快速释放、learning→稳步增益、building→蓄势跃迁、connecting→协同放大。AI可根据资料提出初步建议，assumptions保留联想/待确认前提；海报标明初步画像。不能捏造经营事实。优势类型不锁定曲线。

四套模板统一纵轴为“同等团队与时间下，可稳定承担的业务量”，横轴为AI化推进过程，三阶段和示意终点一致。不接收企业自定义曲率、指标、增长比例、营收或时间预测。形态为条件情景，不能据此保证实际效果。

## 本地维护

无需运行时依赖：`python3 build.py` 生成dist/index.html；`python3 publish.py` 同步GitHub Pages的docs目录。`node --test tests/*.test.cjs` 执行新版合同与旧版回归。app/poster-assets.js保存已批准样张的六类视觉和四个固定曲线组，渲染器仅替换受约束文案；字体授权见app/Outfit-OFL.txt。

schema1.0至4.0原参数完整保留，不从单项任务推断企业整体。旧版任务判断不升级为企业优势；GAIDN-4.0/enterprise/focus_work变体可识别并复制升级提示词，只向AI传业务摘要，旧字段不会混入新版规则。草稿保存在当前标签页sessionStorage，关闭后清除；可下载JSON以便继续。

app/analytics-config.json限定GA4可触发的生产域名；analytics.js只接受技术事件白名单。业务信息、诊断参数和图片在本机处理，不发送至GA。妙搭副本保留自己的域名配置。

## 对话与导入规则（5.1）

客户讲生意，AI负责类型、路径、优势线索与文案；先给一个经营新认识，最多追加一轮一个问题。AI推断必须进assumptions，事实摘要进evidence；获客失败本身不构成专家优势。提示词明确废弃旧版字段，输出仍兼容schema5.0。

导入接受英文枚举/对应中文名称、单字符串列表或标题、外带说明的单份JSON。只有业务描述和优势类型是出图必要条件；欠缺文案按类型补作建议，路径未说明时按先组织再验证的条件情景探索，明确标识推测，不认定企业成熟度。完全空白或未给企业类型时不硬猜。

海报长文案自动缩字号/换行，极长内容在展示时省略并保留参数原文；不让老板承担排版。四套曲线和已批准六种视觉保持固定，六个完整示例与批准图逐像素一致。真实外部模型的新对话遵循度与老板感受需另行验证。
